# Talks and writing

Ideas, examples and images for writing or speaking about how this map was made. Each folder is one theme, with its own notes and the images that go with them.

- [`placement/`](placement/README.md): putting a novel's places on the ground, where an LLM working from memory goes wrong, and how it does much better when it reaches for real geodata and standard tools.

Screenshots here are of the site itself, and figures are drawn from open data. The images are kept out of the repository (`.gitignore`), as they come to about 50 MB. `tools/placement-shots.mjs` takes the screenshots, and the figures come from `crossing.landform_points_images` and `crossing.escarpment_view --figure`. Nothing from the novel's text goes in this folder (see `CONTRIBUTING.md`).
