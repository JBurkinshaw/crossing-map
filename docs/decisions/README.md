# Decision records

One file per decision, in the order made. The site's "How it's built" page renders these files, so they are the project's real decision log.

Each record has four parts: **Context** (the problem), **Decision** (what we do), **Alternatives** (what we rejected and why), and **Consequences** (what follows, good and bad). A record is not edited after it is accepted. A later record supersedes it and says so.

Template:

```markdown
# NNNN. Title

Status: accepted (YYYY-MM-DD) | proposed | superseded by NNNN
Phase: P1 | P2

## Context
## Decision
## Alternatives
## Consequences
```
